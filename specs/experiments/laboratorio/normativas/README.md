# Normativas

- **Status:** Approved pelo proprietário em 2026-11-06.
- **Parte de:** [Laboratório de avaliação do Chain](../README.md).

As normativas são a origem das dez mudanças do laboratório (LQ-08, LQ-09). As regras estão em [objetivos.md](../objetivos.md) §5.

**Cada arquivo tem só o que o agente recebe.** O arquivo traz as restrições, nunca a alteração a fazer, e não aponta para nenhuma outra spec. A alteração prevista fica em [alteracoes-previstas.md](../alteracoes-previstas.md), que não é entregue aos agentes (LQ-11).
